jot jot boom

Notes that look like notes, written in plain markdown, kept in plain files.

A retro notes app for the COSMIC desktop. Type markdown; see a page. Your notes are .md files in a folder you own, with pictures in frames, folders with 8-bit icons, sixteen colour themes, and one hidden one.

The Terminalator theme · editor only · Ctrl+Shift+0
why it exists

Write it down. Keep it yours.

Most note apps ask you to trust a database you can't open. JotJotBoom asks nothing: every note is a markdown file in ~/Documents/JotJotBoom, readable by anything, searchable by grep, syncable by whatever you already use. The app keeps an index so search is instant, and the index is disposable — delete it and it rebuilds from your files.

On top of that plain foundation sits an editor that renders markdown as you write it: headings grow, markers hide, task boxes are boxes, and a picture is a picture — in a frame, if you like. It's the writing experience you'd expect from the best notes apps, on Linux, with a green phosphor glow.

the editor

Markdown in, page out.

Headings render at real sizes. **bold** becomes bold and the stars disappear. Double-click any line to see and edit its markdown; click away and it's a page again. Wiki-links open notes with Ctrl+click, tags are coloured, quotes get a bar.

  • Type [] at the start of a line — instant task box.
  • --- becomes a real rule the moment you press Enter.
  • Pictures float left or right; text wraps around them.
  • Every note starts as a heading, so the title is the first line.
pictures

Drop a photo. Pick a frame.

Drag an image in from your file manager and a line shows exactly where it will land. Then choose how it's printed: a plain box, phosphor tint, dithered, a CRT bezel, an instant print with a caption, a film strip, chunky pixels, ASCII art, or a comic book panel with a yellow caption box.

  • Drag the ◢ corner to resize; drag the picture itself to move it.
  • Frames are retro treatments applied on the fly — the original file is untouched.
  • The picker shows thumbnails in a grid.
tasks

Tick it. Or duck it.

Click a box to finish a task; the text fades and strikes through. What goes in the brackets is up to you — an x, a tick, a dash, a star, a duck, a pizza. It's written into the file, so it's your list, not the app's.

  • Heading, bullet and to-do buttons work across a whole selection.
  • Fourteen completion marks in Options → Tasks.
  • Recipes, packing lists, shopping — the boxes line up with the bullets.
colour & type

Sixteen themes, eight pairings.

Green phosphor, amber, WordPerfect blue, synthwave, plain white paper and eleven more, each named after something from the eighties. Fonts come as designer pairings — a title face, a chrome face, a note face — from IBM Plex to Spectral over Lato to a typewriter, all bundled, all free. Sizes are set per pane with live samples; the note column has four fish-rated widths.

  • The launcher icon repaints itself in your theme's colours.
  • Options open beside the note, never over it — Alt + ,.
folders

Tags that nest, icons that don't blur.

#travel/japan makes a folder inside a folder. Fold them, rename one and every note updates, right-click for an 8-bit icon — twenty-one one-colour pixel glyphs drawn in the theme's tag colour, crisp at any size, and not an emoji in sight. A tag about coffee wears a cup without being asked.

  • ↑ ↓ walk the notes list like mail.
  • Search is instant, across everything, as you type.

Files first

Markdown with a tiny frontmatter (an id, a date, a pin). Open them in anything. Back them up with anything. Nothing lives only in the app.

Autosave, quietly

A ✓ in the corner is the whole save UI. Click it for the last save time. If a save ever fails, it tells you, keeps the edit, and retries.

Keyboard for all of it

Every action has a shortcut and every shortcut is in the menu. Ctrl+Shift+H shows the whole map.

There is a neon sign in this app. Press Ctrl+Shift+Enter and a braille-dot cup lights up over the window, steam drifting, tubes buzzing, like an alley in Tokyo at two in the morning. Any key turns it off. There is also a seventeenth theme. It is not in the list. Search for something you love.
