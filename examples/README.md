# Example notes

Made-up notes that show the app off: a letter, journals, a packing list,
a recipe, a coffee log, an index that links them, and a two-week Japan
trip under Travel → Japan, nine days in the South of France and ten in
Tuscany: daily journals (famous places and odd ones), a plan per trip that
links them and a budget whose tables add themselves up. They are plain
markdown; the app stamps ids into them on first open.

Install into your notes folder with `just install-examples` (it never
overwrites a note that already exists).
