# Examples — start here

A handful of made-up notes that show what this app can do. Every one is a plain markdown file in your notes folder — open it in any editor and it still reads.

## What's in the box

- [[Letter to Mum, from Kyoto]] — a letter, with a typewriter and a quote
- [[Kyoto, night one]] — a travel journal with photos in retro frames
- [[Fiji packing list]] — a to-do list, half done, with a duck
- [[The cabin weekend]] — headings, a rule, and two snowy pictures
- [[Tonkotsu ramen, the long way]] — a recipe with ingredients to tick off
- [[Coffee log]] — the tag wears a cup; try searching for *coffee*
- [[Morning pages]] — bold, italic, ~~struck~~ and a wiki link back here

## Things to try

1. Double-click a line to see its markdown; click away and it renders again.
2. Drag any picture to a new line — the drop line shows where it lands.
3. Right-click a tag on the left → **icon…** for an 8-bit folder icon.
4. Press **Alt + ,** for Options: colours, fonts, sizes, task marks.
5. Type `[]` at the start of a line. Then press **Ctrl+Shift+Enter**.
